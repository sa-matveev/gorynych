# Прогнозирование финансовой отчетности компаний

## О проекте

Проект посвящён сбору, структурированию и анализу финансовых данных публичных компаний с целью построения моделей прогнозирования их будущих финансовых показателей.

На первом этапе проекта формируется единая база данных на основе:

- финансовой отчетности компаний;
- официальных раскрытий и корпоративных документов;
- макроэкономических показателей;
- рыночных данных;
- других доступных открытых источников.

После подготовки данных планируется исследовать, насколько хорошо различные методы машинного обучения могут прогнозировать будущие показатели финансовой отчетности компаний.

В дальнейшем проект может быть расширен за счёт использования дополнительных источников данных и моделирования взаимосвязей между компаниями и внешней экономической средой.

---

## Цель проекта

Собрать и структурировать финансовые данные компаний и на их основе построить модели для прогнозирования будущих показателей отчетности.

---

## Основные задачи

- собрать финансовую отчетность публичных компаний;
- автоматизировать получение данных из открытых источников;
- привести данные разных компаний и периодов к единой структуре;
- сформировать исторический датасет для машинного обучения;
- провести исследовательский анализ данных;
- построить базовые модели прогнозирования;
- попробовать прогнозировать показатели финансовой отчетности на следующие периоды;
- сравнить различные подходы и определить наиболее перспективные направления дальнейшего исследования.

## План работы

### 1. Сбор данных

Сбор финансовой отчетности компаний и дополнительных данных из открытых источников.

### 2. Структурирование данных

Очистка, нормализация и приведение финансовых показателей к единому формату.

### 3. Формирование датасета

Создание исторической выборки, пригодной для анализа и обучения моделей машинного обучения.

### 4. Исследовательский анализ

Анализ динамики финансовых показателей, взаимосвязей между признаками и качества собранных данных.

### 5. Базовое прогнозирование

Построение простых статистических и ML-моделей для прогнозирования отдельных финансовых показателей.

### 6. Прогнозирование отчетности

Исследование возможности совместного прогнозирования нескольких показателей финансовой отчетности компании.

### 7. Улучшение моделей

Добавление внешних факторов: макроэкономических показателей, рыночных данных и информации о других компаниях.

### 8. Анализ результатов

Сравнение моделей, оценка качества прогнозов и определение направлений дальнейшего развития проекта.
